Borrowing & returns

Use the existing Oracle APEX application to issue and return equipment. These actions must run behind an authenticated application, where database triggers and constraints protect records.

This GitHub Pages website shows live inventory, but it cannot safely store database passwords or secret write tokens. Your Oracle APEX application already provides the protected Borrow and Return workflows. Sign in to your Oracle APEX workspace and open your existing equipment-management application.

The public inventory refreshes from Oracle; after an issue or return in APEX, click Refresh Oracle data above to view the updated equipment status.

Read-only public inventory. No borrower names, emails, loan records, passwords or API write credentials are sent to this website.
